# Clone Blinkit - Grocery Delivery Website

A responsive grocery delivery website interface inspired by Blinkit, developed using **HTML5 and CSS3**.

## About the Project

Clone Blinkit is a frontend web development project created to practice and improve HTML and CSS skills. It represents a grocery delivery website interface with product categories, promotional banners, product cards, and navigation sections.

## Technologies Used

- **HTML5** - Website structure
- **CSS3** - Styling and responsive layout
- **Font Awesome** - Icons

## Features

- Header section with logo and delivery information
- Search bar and navigation buttons
- Promotional banner section
- Grocery product categories
- Product cards with images, names, and prices
- CSS hover effects
- Responsive layout for mobile screens
- Footer section

1. Clone or download this repository.
2. Open the project folder.
3. Open the `index.html` file in your browser.
